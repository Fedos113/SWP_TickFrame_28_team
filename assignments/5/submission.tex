\section{MVP v2 Access Instructions}

The MVP v2 increment is delivered as a Docker Compose stack with two services: the TickFrame web application (port 8080) and the ML microservice (port 8001).

\subsection{Docker Deployment (Recommended)}
\begin{enumerate}[leftmargin=*]
    \item Clone the repository at the submission commit:
\begin{verbatim}
git clone https://github.com/Fedos113/SWP_TickFrame_28_team.git
cd SWP_TickFrame_28_team
git checkout 193de326e39943443afc0fa1546d465f214841ed
\end{verbatim}
    \item Copy the environment template:
\begin{verbatim}
cp .env.example .env
\end{verbatim}
    \item Build and run with Docker Compose:
\begin{verbatim}
docker compose up --build
\end{verbatim}
    \item Open \texttt{http://localhost:8080} in a browser (host port mapped to 8080 by default).
\end{enumerate}

\subsection{Local Development (No Docker)}
\begin{enumerate}[leftmargin=*]
    \item Clone and checkout as above.
    \item Create a virtual environment and install dependencies:
\begin{verbatim}
python -m venv .venv
.venv\Scripts\Activate.ps1  # Windows
# source .venv/bin/activate  # Linux/macOS
pip install -r requirements.txt
pip install -r tests/requirements.txt
\end{verbatim}
    \item Start the FastAPI server:
\begin{verbatim}
uvicorn tickframe.backend.main:app --host 0.0.0.0 --port 8000
\end{verbatim}
    \item Open \texttt{http://localhost:8000} in a browser.
\end{enumerate}

\subsection{Verification}
Once the server is running, confirm:
\begin{itemize}
    \item \texttt{GET /api/health} --- returns \texttt{\{"status":"ok"\}}
    \item \texttt{GET /api/coins} --- returns 10 trading pairs with live prices
    \item \texttt{GET /api/coins/BTCUSDT/candles?interval=5m\&limit=200} --- OHLCV candle data
    \item \texttt{POST /api/analyze/BTCUSDT} --- pattern analysis endpoint
    \item \texttt{WS /ws/candles/BTCUSDT?interval=5m} --- real-time candle stream
    \item Volume sub-chart visible below main chart
    \item Multi-interval selector (5m, 15m, 1h, 4h, 1d) functional
    \item Analysis range slider visible in settings
\end{itemize}
